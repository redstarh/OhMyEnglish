# 첫 4주 학습 플로우

기본 리듬은 주 5회, 회당 10~15분이다. 월~목은 새 발화와 짧은 복습, 금요일은 역할극·주간 분석, 주말은 선택형 쉐도잉이다. 권장량 완료 후에도 추가 학습은 언제나 가능하다.

| 주차 | 목표 | 말하기 과제 | 오류 재학습 | 완료 기준 |
|---|---|---|---|---|
| 1주차 | 진단과 일상 발화 자동화 | 자기소개, 오늘 한 일, 계획, 작은 부탁 | 상위 2개 문법 패턴을 1·3일 간격으로 복습 | 30초 일상 업데이트 |
| 2주차 | 기본 업무 업데이트 | 했던 일, 진행 중인 일, 다음 행동 | 시제·전치사·기본 업무 동사 변형 | 45초 daily update |
| 3주차 | 이슈와 협업 대화 | blocker, 일정 변경, 도움 요청, 우선순위 | 개인 상위 오류를 3개 업무 문맥에서 반복 | 회의형 Q&A 3턴 |
| 4주차 | 구조적 프로젝트 보고 | status, risk, ask, next step | 1·3·7일 복습과 쉐도잉 문장 전이 | 60초 프로젝트 상태 보고 |

## 일일 세션 템플릿

1. **Warm-up (2분):** 전날 패턴 한 개를 일상 문장으로 말한다.
2. **Scenario (5분):** 오늘의 역할극을 한다.
3. **Repair (3분):** 가장 중요한 오류 1~2개를 수정·변형한다.
4. **Transfer (2분):** 같은 구조를 본인의 실제 상황으로 바꿔 말한다.
5. **Close (1분):** 다음 복습일과 짧은 준비 과제를 확인한다.

## 반복 질문·답변 드릴

매일 세션의 첫 2~3분 또는 추가 학습 모드로 사용한다. 하나의 문형을 최소 세 상황에서 말한다.

| 목표 문형 | 질문 예시 | 업무 전이 |
|---|---|---|
| `I usually...` | What do you usually do after work? | What do you usually check first in the morning? |
| `I need to...` | What do you need to do tonight? | What do you need to finish before the meeting? |
| `I went...` | Where did you go last weekend? | Which team did you talk to yesterday? |

## 추가 학습 진입

- **질문 5개 더:** 오늘 문형으로 새 질문 다섯 개
- **약점 집중:** 다음 복습 예정 오류 중 하나를 즉시 연습
- **자유 대화:** 사용자가 고른 일상 주제로 5~10분 대화
- **업무 역할극:** 현재 주차의 IT 시나리오 난이도로 추가 대화

## 주차별 대표 시나리오

- 1주차: “오늘 무엇을 했나요?”, 카페 주문, 약속 변경
- 2주차: 어제/오늘/내일 업무 업데이트, 작업 요청
- 3주차: API 지연, 테스트 실패, 도움이 필요한 상황
- 4주차: “이번 주 프로젝트는 계획대로 진행 중입니다…”로 시작하는 이해관계자 보고
