## v1.0 → v1.1 차이 확인 방법

```bash
diff docs/backup/v1.0/PRD.md <(head -118 docs/PRD.md)
#   → 1행(제목·버전 표기)과 39행(비범위 경계)만 다르다. §1~9의 줄 번호는 하나도 움직이지 않았다.

diff docs/backup/v1.0/requirements-summary.md <(head -60 docs/requirements-summary.md)
#   → 1행만 다르다.
```

**줄 번호를 보존한 이유**: 승인된 설계서·수용 기준·handoff가 `PRD.md`를 `:29`~`:117`,
`requirements-summary.md`를 `:15`~`:60` 범위에서 줄 단위로 인용한다(2026-08-27 실측 13곳·5곳).
중간 삽입은 그 인용을 전부 깨뜨린다. 편집 규약은 각 문서의 맨 아래 절에 있다.
