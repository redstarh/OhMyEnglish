01 · REQUIREMENTS

요구사항

학습자 프로필(현재 수준·요구·목표)이 문구 난이도와 교정 우선순위의 정본이고, 기능 범위는 docs/PRD.md와 docs/design/ 설계서가 정한다.

현재 수준

  • 하루 일상을 간단한 문장으로 이야기할 수 있음
  • 간단한 인사와 small talk 가능
  • I want to ~ · I need to ~ · I'd like ~ 중심의 단문 발화
  • 일상 단어는 듣고 이해함
  • 긴 문장으로 이유·진행 상황·문제점을 설명할 때 부담을 느낌

목표 수준

  • 사내 비즈니스 미팅에 참여해 의견 말하기
  • IT 프로젝트를 리딩하며 일정·리스크·의사결정 설명
  • AWS Engage Manager에게 구조적 보고:
    Current status → What changed → Risks / blockers → Decision needed → Next steps

학습 방향 — 교정이 아니라 다음 발화를 바꾸는 것

SPEAK FIRST

문법 설명보다 말하기 우선. 세션 발화량의 65% 이상을 사용자에게 할당한다.

REMEMBER

틀린 문장이 아니라 재사용 가능한 패턴으로 저장한다 — unique(user_id, pattern_key).

TRANSFER

일상 → 업무 업데이트 → blocker/리스크 → 프로젝트 보고 순으로 난이도를 올린다.

  • 한 세션에서 핵심 오류 1~2개만 교정하고, 교정 문장을 다른 상황에서 다시 말하게 한다
  • 같은 문형을 최소 3~5개의 다른 질문에서 반복한다
  • 하루 10~15분이 기본 학습량이고, 채운 뒤에도 추가 학습을 제한 없이 시작할 수 있다
  • 같은 오류는 1일 · 3일 · 7일 뒤 다른 상황으로 다시 연습한다
