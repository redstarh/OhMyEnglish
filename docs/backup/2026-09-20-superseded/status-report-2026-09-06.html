애플리케이션 아키텍처 (단순 버전)

#모듈무엇을 하나
1frontend/app/page.tsx학습자가 시작 버튼을 누른다. 이 화면이 다음 세션의 추천 이유와 목표 수준을 한 줄로 보여준다
2backend/api/ws음성 연결을 연다. 시작 시점에 준비된 계획을 읽는다(없으면 계획 없이 시작한다)
3audio_gateway/factory:create_voice_adapter계획을 데이터로 받아 음성 어댑터를 만든다 (통로를 둘로 늘리지 않기 위해 포트는 손대지 않는다)
4audio_gateway/nova:build_system_prompt불변 대화 규칙 + 오늘의 계획(목표 수준·초점·문장 길이·상황·힌트 시점)을 합쳐 지시문을 만든다
5[외부] Amazon Nova Sonic실시간 음성 대화. 발음 판정도 이 모델이 한다(우리가 점수를 발명하지 않는다)
6audio_gateway/session전사문을 저장하고 분석 작업을 큐에 넣는다. 조각난 발화는 턴 경계까지 모은다
7services/analysis → [외부] Claude문법 오류를 분석해 오류 패턴으로 저장한다
8services/review:recompute복습 주기(1·3·7일)와 숙련도를 갱신한다. 재발하면 되돌린다
9services/sessions:end_session세션을 닫고 같은 트랜잭션에서 다음 계획 작업을 등록한다 (사용자가 기다리는 경로에 모델 호출이 없다)
10services/plan:process_plan → [외부] Claude다음 세션 계획을 만들어 저장하고 학습자 수준을 갱신한다 → 다시 1번으로

뼈대를 한 문장으로: 대화는 음성 모델이, 판단은 글 모델이, 순서와 저장은 우리 코드가 맡는다 — 그래서 학습자가 기다리는 경로(1~6)에는 글 모델 호출이 하나도 없고, 판단(7~10)은 전부 세션이 끝난 뒤에 돈다. 이번 슬라이스에서 10번 → 1·2번으로 되돌아오는 고리가 처음 닫혔다.

미결정 — 사람의 결정을 기다린다 (7건)

7건 전부 이 턴에 원장·코드·데이터베이스에서 아직 살아 있는지 확인했다. 이전 판의 8건 중 1건은 미결정이 아니었다(아래 상자).

#무엇을 결정하나왜 지금 막혀 있나
1⏸ 마이그레이션 007을 개발 DB에 적용할까되돌리기 어렵다. 아직 안 했기 때문에 오염된 입력으로 만든 계획이 존재하지 않는 상태가 유지된다. 직접 조회로 미적용 확인(적용 이력 001·003·004·005·006, 계획 표 0개)
2⏸ 실물 글 모델로 계획을 1회 만들어 볼까비용이 든다. 자동 검사는 전부 대역이라 실물 왕복 0회가 남는다. AC11-2 판정이 여기 걸려 있다
3⏸ 발음 소리 키의 값 범위가 §10 의도와 어긋나는가관측 3건에 음소 치환이 하나도 없다(축약형·관사 — 발음이 아니라 문법에 가깝다). 표본이 작아 마이크 세션이 더 필요하다
4⏸ 발음 패턴 키의 값 범위를 열거해 고정할까실물 관측이 부족해 표시 사전을 만들면 발명한 값이 코드에 굳는다. 3번과 같은 뿌리라 함께 판정해야 한다
5⏸ 복습 과제 행의 정체성 경계재계산이 "지우고 다시 넣기"라 번호와 상태가 매번 초기화된다. 읽는 코드가 0곳이라 지금은 무해하다(이 턴에 재확인) — 화면이 과제 번호로 "완료 표시"를 하기 전에 정해야 한다
6⏸ AC11-5를 언제 닫을까실물 음성 응대가 달라지는 것을 요구해 이번 슬라이스 밖으로 이월됐다
7⏸ 원격 저장소 생성·연결git remote가 비어 있다(이 턴에 확인). 밀어 올릴 대상이 없다 — 저장소 생성은 캡틴 몫이다
이전 판에서 미결정으로 잘못 올린 것 1건 — 정정한다. "발음 도구 응답을 돌려보내지 않는 것이 여러 턴에서도 안전한가"는 미결정이 아니다. 결정은 2026-08-28에 이미 내려졌다("보내지 않는다 — 관측된 거동을 따른다"). 남은 것은 결정이 아니라 검증이고(관측이 1회뿐), 5차수 관측 대상으로 예약돼 있다. 규약이 금지한 "이미 결정된 것을 미결정으로 올리기"에 해당해 미결정 절에서 뺐다 — 그대로 두면 캡틴에게 이미 내린 결정을 다시 묻는 보고가 된다.
이미 결정된 축소(되돌릴 대상이 아니다): 세션당 교정 1~2개 상한을 코드로 강제하지 않고 지시문 문구로만 좁힌다 · 재발화 기회는 1회 · 음성 명령 제어는 3단계로 이연 · 발음 성과를 난이도 판단에 넣지 않는다(MVP 이후 재검토) · 발음 패턴은 복습 일정에 넣지 않는다.
