핵심 요구사항

일상 영어부터 IT 프로젝트 리딩과 AWS Engage Manager 보고까지, 말하기 중심으로 성장하는 개인화 영어 학습 Agent

영어 수준학습 방식반복 오류하루 학습업무 영어음성 대화최종 목표
01 · CURRENT LEVEL

나의 영어 수준

  • 하루 일상을 간단한 문장으로 이야기할 수 있음
  • 간단한 인사와 small talk이 가능한 수준
  • I want to ~, I need to ~, I'd like ~ 등 간단한 패턴으로 단문 위주로 이야기함
  • 일상 단어는 이해하고 들을 수 있음
  • 긴 문장으로 이유, 진행 상황, 문제점을 설명할 때 부담을 느낌
02 · SPEAKING FIRST

학습 방향

말하기 중심

  • 문법 설명보다 Speaking을 우선함
  • 내가 세션의 65% 이상 말함
  • 한 번에 질문 하나씩 받음

일상 → 업무 확장

  • 일상 대화로 자신감 형성
  • 업무 업데이트와 협업으로 확장
  • 프로젝트 보고까지 단계적으로 학습

일상 질문·답변 반복

하나의 문형을 최소 3~5개의 질문에서 사용합니다.

What do you usually do after work?
I usually watch a movie after work.

What do you usually do on weekends?
I usually meet my friends on weekends.
03 · PERSONAL MEMORY

반복 오류 학습

  • 시제, 관사, 전치사, 어순, 동사 형태, 업무 표현, 발음·억양을 분석함
  • 틀린 문장만 저장하지 않고 재사용할 수 있는 패턴으로 기억함
  • 같은 오류를 1일, 3일, 7일 뒤 다른 상황에서 다시 연습함
  • 내가 자주 틀리는 패턴을 직접 선택해서 학습을 만들 수 있음
예시: 과거 시제 업무 보고
틀린 문장 · Yesterday I work on the API.
목표 문장 · Yesterday, I worked on the API.
다음 행동 · 일상, 업무 업데이트, 일정 변경 상황에서 다시 말하기
04 · DAILY & EXTRA

하루 학습 방식

기본 학습 · 10~15분

  1. 전날 패턴 짧게 복습
  2. 오늘의 일상 또는 업무 대화
  3. 핵심 오류 1~2개 교정
  4. 다른 상황에서 다시 말하기
  5. 다음 복습 일정 확인

추가 학습 · 제한 없음

  • 자유 대화
  • 질문 다섯 개 더
  • 자주 틀리는 패턴 집중
  • 업무 역할극
  • 쉐도잉

일일 목표는 권장량이며, 학습을 막는 제한이 아닙니다.

주간·월간 분석

  • 가장 많이 틀린 문법과 구문
  • 지난주·지난달보다 좋아진 패턴
  • 다음에 다시 연습할 문장과 업무 상황
  • 일상 대화, 회의, 보고 영어의 변화
05 · SHADOWING

쉐도잉과 영상 학습

  • 30~90초의 짧은 영상 또는 오디오 사용
  • 듣기 → 문장 단위 따라 말하기 → 천천히 다시 듣기 → 녹음 → 내 상황에 맞게 바꿔 말하기
  • 필요하면 YouTube 영상 후보를 주제와 수준에 맞춰 추천
  • 사용자가 선택한 짧은 구간만 학습 과제로 사용
