01 · PRODUCT PRINCIPLE

교정이 아니라, 다음 발화를 바꾸는 학습

Agent는 사용자의 발화를 짧게 교정하고 끝내지 않습니다. 오류를 재사용 가능한 패턴으로 저장하고, 다른 상황에서 다시 말하게 하며, 충분히 성공하면 난이도를 올립니다.

SPEAK FIRST

사용자가 더 많이 말한다

일상 대화와 반복 질문·답변을 매일 훈련합니다. 세션 발화량의 65% 이상을 사용자에게 할당합니다.

04 · VOICE + UI CONTROL

버튼으로도, 말로도 학습을 움직인다

모든 핵심 행동은 UI와 음성 명령을 동시에 제공합니다. 처음에는 버튼을 눌러 명령하는 방식을 기본으로 두고, 활성 학습 중에는 “Oh My English” 호출어로 학습 답변과 제어 발화를 구분합니다.

UI 제어

추가 학습 · 질문 5개 더 · 힌트 · 반복 · 속도 낮춤 · 다음 문제 · 일시정지 · 종료

음성 제어

“추가 연습 시작”
“Oh My English, 질문 다섯 개 더”
“Repeat that slowly.”
“힌트 줘”

안전 규칙

종료·삭제는 한 번 더 확인합니다. 학습 답변은 명령으로 오인하지 않습니다.

06 · FIRST FOUR WEEKS

일상에서 프로젝트 보고까지

Week 1 — 일상 발화

자기소개, 오늘 한 일, 계획. 상위 오류 2개를 진단하고 30초 업데이트를 완성합니다.

Week 2 — 업무 업데이트

어제·오늘·내일 업무를 45초로 보고합니다.

Week 3 — 이슈와 협업

blocker, 도움 요청, 일정 변경을 회의 Q&A로 연습합니다.

Week 4 — 프로젝트 상태 보고

Status / Change / Risk / Ask / Next step 구조로 60초 보고합니다.
