# OhMyEnglish 핵심 요구사항 정리 · **v1.1** (개정 이력은 맨 아래 · 이전 판 `docs/backup/v1.0/`)

## 나의 영어 수준

- 하루 일상을 간단한 문장으로 이야기할 수 있음
- 간단한 인사와 small talk이 가능한 수준
- `I want to ~`, `I need to ~`, `I'd like ~` 등 간단한 패턴으로 단문 위주로 이야기함
- 일상 단어는 이해하고 들을 수 있음
- 긴 문장으로 이유, 진행 상황, 문제점을 설명할 때 부담을 느낌
- 시제, 전치사, 어순, 업무 표현에서 같은 실수를 반복할 수 있음

## 학습 방향

- 문법 설명보다 **Speaking 중심**으로 학습함
- 한 번에 너무 많은 오류를 고치지 않고, 가장 중요한 오류 1~2개만 교정함
- 교정한 문장은 다시 말하고, 비슷하지만 다른 상황에서도 반복해서 말함
- 학습은 일상 대화에서 시작하고, 업무 대화와 프로젝트 보고로 점진적으로 확장함
- 학습 권장량을 완료한 뒤에도 원하면 언제든 추가 학습을 할 수 있음

## 일상 대화 학습

- 매일 짧은 일상 대화를 학습함
	- 인사
	- 오늘 한 일
	- 내일 계획
	- 식사, 취미, 약속
	- 감정, 부탁, 의견 말하기
- 같은 문장 패턴을 질문과 답변으로 반복 학습함
	- `What do you usually do after work?`
	- `I usually watch a movie after work.`
	- `What do you usually do on weekends?`
	- `I usually meet my friends on weekends.`
- 하나의 패턴은 최소 3~5개의 다른 질문에서 말해 봄
- 일상 문장에서 익힌 패턴을 업무 문장으로 바꿔 말해 봄
	- `I need to buy groceries.`
	- `I need to finish the test report.`

## 반복 오류 학습

- 내가 반복적으로 틀리는 문법과 구문을 기억함
	- 시제
	- 관사
	- 전치사
	- 어순
	- 동사 형태
	- 업무 영어 표현
	- 발음과 억양
- 틀린 문장만 저장하지 않고, 재사용할 수 있는 패턴으로 저장함
	- 예: `past_tense_in_work_update`
	- 틀린 문장: `Yesterday I work on the API.`
	- 목표 문장: `Yesterday, I worked on the API.`
- 같은 오류는 1일, 3일, 7일 뒤에 다른 상황으로 다시 연습함
- 사용자는 자주 틀리는 패턴을 직접 보고, 해당 패턴으로 즉시 학습을 만들 수 있음
	- “이 문법으로 연습 만들어줘”
	- “과거 시제 질문 다섯 개 더”

## 하루 학습 방식

- 기본 학습량
	- 하루 10~15분
	- 말하기 중심
	- 일상 질문·답변 + 역할극 + 오류 복습
- 기본 학습 순서
	- 전날 틀린 패턴 짧게 복습
	- 오늘의 일상 또는 업무 상황 대화
	- 중요한 오류 1~2개 교정
	- 같은 표현을 다른 상황에서 다시 말하기
	- 다음 복습 일정 확인
- 추가 학습
	- 하루 학습량을 모두 채운 뒤에도 추가 학습 가능
	- 자유 대화
	- 질문 다섯 개 더
	- 자주 틀리는 패턴 집중
	- 업무 역할극
	- 쉐도잉

## 주간·월간 학습 분석

- 주간 분석
	- 이번 주에 가장 많이 틀린 문법과 구문
	- 지난주보다 좋아진 패턴
	- 다음 주에 다시 연습할 문장 패턴
	- 일상 대화와 업무 영어 학습 비중
- 월간 분석
	- 반복 오류가 얼마나 줄었는지
	- 말하는 문장 길이가 얼마나 늘었는지
	- 일상 대화, 회의, 보고 영어 수준 변화
	- 다음 달에 집중할 업무 상황

## 쉐도잉과 영상 학습

- 30~90초 길이의 짧은 영상 또는 오디오를 사용함
- 쉐도잉 순서
	- 먼저 듣기
	- 문장 단위로 따라 말하기
	- 천천히 다시 듣기
	- 내 발화 녹음하기
	- 내 업무 상황에 맞게 문장 바꿔 말하기
- 필요하면 YouTube 영상 후보를 주제와 수준에 맞게 추천함
	- 전체 영상을 무작정 저장하지 않음
	- 사용자가 선택한 짧은 구간만 학습 과제로 사용함

## 발음 교정 학습 (v1.1 신설)

- 발음이 틀리면 Agent가 **올바른 발음으로 그 문장을 다시 읽어줌**
	- 어떤 소리가 틀렸는지 짚어 줌
	- 그다음 내가 따라 말함
	- 따라 말한 결과를 기록함 (성공 / 실패 / 판정 불가)
- 발음 판정은 **내 목소리를 직접 듣는 실시간 음성 모델**이 함
	- 전사문(글자로 바뀐 내 말)으로는 발음을 알 수 없음
	- 내가 `sink`라고 말해도 전사문에는 `think`로 적히기 때문
- 두 가지는 기계가 확실히 알 수 있어서 함께 기록함
	- 전사문에 한글이 섞이는 경우 (억양이 너무 강해서 영어로 안 들린 것)
	- Agent가 "다시 말해 주세요"라고 되물은 경우
- 평소 세션에서는 문법 교정이 우선이고, 위 두 신호가 뜰 때만 발음에 바로 개입함
	- 발음만 집중해서 연습하고 싶으면 **추가 학습에서 `발음 집중`을 고름**
- 발음 오류도 다른 오류처럼 패턴으로 기억해서 다음 학습에 다시 나옴
- 내 목소리 녹음은 기본으로 저장하지 않음. 남는 것은 판정 결과와 시범 문장임
- 하지 않는 것
	- 발음 점수 매기기, 발음 등급, 원어민과 얼마나 비슷한지 지표
	- 우리가 하는 것은 **시범과 기록**이고 채점이 아님

## 학습 이력으로 다음 학습을 만드는 것 (v1.1 신설)

- 내가 틀린 것을 저장하는 데서 끝내지 않고, **다음 세션에서 실제로 쓰임**
	- 지금은 저장은 되는데 다음 학습이 늘 똑같음
- 세션마다 "오늘 무엇을 어떻게 연습할지"를 내 오류 이력에서 정함
	- 오늘의 초점 패턴 1~2개
	- 그 패턴을 유발하는 질문 3~5개
	- 오늘의 난이도
	- **왜 이걸 연습하는지 이유** — 화면에서 볼 수 있어야 함
- 계획은 **직전 세션이 끝날 때 미리** 만들어 둠
	- 학습 시작 버튼을 누르고 기다리는 일이 없어야 함
- 계획이 없거나 만들기에 실패해도 **학습은 그냥 시작됨**
- 복습 1일·3일·7일이 실제로 돌아감
	- 또 틀린 패턴은 주기를 **되돌림** (다시 1일로)
	- 또 틀린 걸 7일 뒤로 미루면 복습이 의미가 없음
- 난이도는 성공률을 보고 조절함
	- 한 번에 한 단계씩만 올림 (A2 → B1 → B2)
	- 너무 어려워지면 **내려가는 것도 허용**
- 무엇이 만성 약점인지는 사람이 숫자로 정하지 않음
	- 조회는 사실만 줌 — 몇 세션에서 재발했는지, 며칠에 걸쳤는지, 얼마나 오래됐는지, 사라졌다 다시 나왔는지
	- 그 사실을 보고 **Agent가 판단함**
- Agent가 관찰 기록을 남김
	- 예: "짧은 문장에서는 관사를 붙이는데 문장이 길어지면 빼먹는다"
	- 덧붙이기만 하고 지우지 않아서, 잘못된 관찰은 되돌릴 수 있음
- 발음 시도 이력도 여기에 들어가서, 발음도 초점 패턴이 될 수 있음

## 업무 영어 학습

- 초기 업무 영어
	- 어제 한 일
	- 오늘 할 일
	- 도움이 필요한 일
	- 일정 변경
- 프로젝트 협업 영어
	- blocker 공유
	- 우선순위 조율
	- 테스트 실패, API 지연, 의존성 이슈 설명
	- 도움 요청과 다음 행동 정리
- 프로젝트 보고 영어
	- 현재 상태: `Current status`
	- 지난 보고 후 바뀐 점: `What changed`
	- 리스크와 blocker: `Risks / blockers`
	- 도움이 필요한 결정: `Decision needed`
	- 다음 행동: `Next steps`

## 목표하는 수준

- 간단한 회사 영어부터 점진적으로 수준을 높임
- 회사 내 비즈니스 미팅에 참여하고 의견을 말할 수 있음
- 나의 업무와 프로젝트 진행 상황을 설명할 수 있음
- IT 회사의 프로젝트를 리딩하고, 일정·리스크·의사결정 사항을 설명할 수 있음
- AWS Engage Manager에게 프로젝트 상황을 구조적으로 보고할 수 있음
	- Current status
	- What changed
	- Risks / blockers
	- Decision needed
	- Next steps

- 화면에서 할 수 있는 기능
	- 오늘 학습 시작
	- 추가 학습 선택
	- 질문 다섯 개 더
	- 힌트 보기
	- 천천히 다시 듣기
	- 다음 문제
	- 학습 일시 정지와 종료
	- 자주 틀리는 패턴 확인
- 음성으로도 같은 기능을 제어할 수 있음
	- “추가 연습 시작”
	- “질문 다섯 개 더”
	- “천천히 다시 말해줘”
	- “힌트 줘”
	- “다음 문제”
	- “오늘 학습 끝낼게”
- 학습 답변과 음성 명령이 섞이지 않도록 함
	- 명령 버튼을 누르고 말하기
	- 또는 “Oh My English”라고 말한 뒤 명령하기

## 음성 대화 구현 방식

- Nova 2 Sonic
	- 사용자의 음성을 듣고 바로 음성으로 대답함
	- 일상 대화, 반복 질문·답변, 짧은 교정, 음성 명령을 담당함
	- 사용자가 Agent 말 중간에 말하면 Agent가 멈추고 다시 들을 수 있음
- Claude Opus 5 on Bedrock
	- 전사문을 분석해서 반복 오류를 찾음
	- 오류 패턴과 복습 일정을 생성함
	- 주간·월간 분석을 작성함
	- IT 프로젝트 보고와 업무 영어 학습 계획을 만듦
- 확정된 기술 선택
	- AWS Region: `us-east-1`
	- 실시간 음성 모델: `amazon.nova-2-sonic-v1:0`
	- 학습 분석 모델: `us.anthropic.claude-opus-5`
	- Backend: Python + FastAPI + `asyncio`
- `us.anthropic.claude-opus-5`는 미국 리전 안에서만 라우팅하는 US geographic 프로필을 사용함
- `global.anthropic.claude-opus-5`는 전 세계 리전으로 라우팅될 수 있으므로 사용하지 않음
- 엄격히 `us-east-1` 단일 리전만 허용해야 하면, 구현 전에 in-region 가용성과 권한을 확인함
- 데이터베이스
	- 학습 세션
	- 사용자 발화 전사문
	- 반복 오류 패턴
	- 복습 과제
	- 주간·월간 리포트를 저장함

## OpenClaw 사용 여부

- 현재 핵심 학습 기능에는 OpenClaw가 필요하지 않음
- 전용 웹/모바일 앱에서 Nova Sonic과 Claude를 직접 연결해서 사용함
- 나중에 Telegram, Slack, WhatsApp으로 복습 알림이나 짧은 텍스트 학습을 보내고 싶을 때 선택적으로 검토함

## 최종 학습 흐름

```text
일상 질문·답변
  → 반복 오류 발견 ─┬─ 문법·표현 오류
  │                └─ 발음 오류 → 올바른 발음 시범 → 따라 말하기 → 결과 기록   (v1.1)
  → 비슷한 문장으로 재학습
  → 업무 상황에 적용
  → 프로젝트 보고 역할극
  → 주간·월간 분석
  → AWS Engage Manager 보고 수준으로 향상

        ↑ 세션이 끝날 때마다 위 이력으로 다음 세션 계획을 만들어 둠            (v1.1)
          (초점 패턴 1~2개 · 질문 3~5개 · 난이도 · 추천 이유 · 복습 1·3·7일 갱신)
```
