## 실측 2026-09-18 — 확인한 것과 확보하지 못한 것

**확인함**: 재생이 안 되는 영상에서 YouTube 의 오류 화면은 **로드 직후가 아니라 재생을 시도한 뒤** 나타남.
로드 후 6초를 기다렸을 때는 재생 버튼만 보였고, iframe 을 클릭해 재생을 시도한 뒤에 영어 오류가 떴음.

**확보하지 못함**: 임베드를 막은 실제 영상 id. 이유 둘 —
⑴ 임베드 차단 여부를 알려 주는 공개 신호가 없음(oEmbed 는 차단 영상에도 200 을 줌 · 설계서 §5 가 이미 적음).
⑵ 후보를 모으려면 `search.list` 가 필요하고 그것은 API 키·쿼터를 들이는 것이라 MVP 범위 밖임(스토리보드 §6).
⇒ ⛔ **이 AC 는 외부 자원에 걸려 있어 이 세션에서 채울 수 없었고, 그것이 지난 세션도 미확인으로 남긴 이유임.**

**대신 찾은 것**: 101·150 만 처리하던 코드 목록 때문에 **목록 밖 오류에서 화면이 조용해지는 구조**를 발견함
→ `TASK-176` 으로 등록해 목록을 없앴음. 그리고 없는 영상은 `onError` 자체가 오지 않는 것을 대조군과 함께
확정함(같은 태스크 노트 · 함정 `H-CB`).

⚠️ **101·150 경로 자체는 여전히 미검증임** — 코드가 무조건 콜백을 부르므로 회귀 위험은 없으나,
「임베드 차단 영상에서 안내가 뜬다」를 실물로 본 적은 없음. 그 영상 id 를 얻는 날에 확인할 자리임.
