## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
사용자 질문(2026-09-09): 쉐도잉 학습 클립을 만들 때 음성 합성을 쓸 수 없나.

확인한 사실 셋: ① shadowing_items 의 source_url 이 nullable 이고 실제 시드 1건(A morning routine before work · 0~30초 · A2)이 그것을 비워 두고 있다 — 즉 출처 없는 항목이 스키마상 정상이다 ② PRD 비범위가 「무제한 YouTube 자동 수집·저작물 전체 저장」을 제외한다 — 외부 콘텐츠를 대량으로 쓰지 않기로 이미 정했다 ③ PRD §4-6 은 「발화 녹음 기반 쉐도잉」이고 클립 상한 90초는 PRD §7 이 정한 값이다.

⛔ 즉 합성음 클립은 저작권 문제를 피하는 길이고 스키마를 바꾸지 않는다. ⚠️ 다만 쉐도잉의 목적이 원어민 발화를 따라 하는 것이라면 합성음이 그 목적에 맞는지가 판단 대상이다 — 그것은 학습 효과 판단이고 사용자 확인이 필요하다. 선행으로 TASK-59 가 Qwen3-TTS 의 영어 품질을 확인해야 한다.
