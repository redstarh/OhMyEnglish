## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
TASK-11 조사에서 발견. 세션 시작이 학습자 수준에 맞는 시나리오 행을 골라 scenario_id를 저장하지만 그것을 읽는 코드가 0곳이다(팀리드 직접 확인: 앱 전체 히트 3개 중 둘은 주석, 하나는 INSERT — select가 없다). learning_scenarios의 prompt_template·title은 백엔드 전체 히트 0건이다. 대화 지시문은 고정 문구 + 계획에서만 온다. 즉 무엇을 골랐든 대화는 같은 문구로 시작한다 — 현황 보고가 적은 '시나리오가 1개로 고정'보다 나쁘고, 이것이 §4-1의 진짜 공백이다. 근거: docs/design/2026-09-06-gap-investigation.md §1.
