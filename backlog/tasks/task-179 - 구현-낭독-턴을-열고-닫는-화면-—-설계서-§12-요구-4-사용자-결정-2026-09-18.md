## 구현 2026-09-18 — 설계서 §12 요구 4 를 채웠음

**바꾼 것 둘**:
- `app/frontend/app/page.tsx` — `startShadowingTurn`·`endShadowingTurn` 콜백 둘을 `useCallback` 으로
  만들어 `ShadowingPanel` 에 넘김. ⚠️ 안정화가 계약임 — 패널이 언마운트 정리에서 닫기를 부르므로
  매 렌더에 새 함수를 주면 정리가 렌더마다 돌아 녹음이 끊김.
- `app/frontend/app/ShadowingPanel.tsx` — 「따라 읽기」/「읽기 끝」 토글 버튼 · 녹음 중 안내
  (`role=status`) · 언마운트 시 열린 턴 닫기 · 녹음 중 「클립 듣기」 잠금.

**판단 셋**:
1. **녹음 시작 시 클립 재생을 끔** — 스피커로 나가는 원본이 마이크로 되돌아오면 저장된 것이 「학습자가
   읽은 것」이 아니게 됨. 그리고 녹음 중에는 「클립 듣기」를 잠가 다시 틀 문을 막음.
2. **소리 없는 클립에서도 「따라 읽기」가 보임** — 전사문만 있어도 읽을 수 있고, 녹음은 클립 오디오와
   무관한 경로임. 실측에서 영상 문장은 `has_audio=false` 였고 그 화면에서 녹음이 정상 동작함.
3. **안내 문구는 「저장된다」까지만 말함** — 저장한 녹음으로 무엇을 하는지는 아직 없으므로 암시하지
   않음(`TASK-128.4` 가 잡은 「없는 기능을 있다고 알리는」 결함 회피).

⛔ **비교·재생은 범위 밖으로 남겼음** — 결정 90 이 기각한 것 중 「녹음」만 해제됐음.

게이트: `tsc` exit 0 · `eslint` exit 0 · `next build` exit 0(`/` 가 `○` Static 유지).
