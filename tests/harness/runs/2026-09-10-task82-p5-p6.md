## 2. ⛔ 워커 드라이버에서 결함 둘 — 하나는 보존 세션을 손상시킬 것이었다

### 2-1. 결함 A — `guard` 의 술어가 `analyze_utterance` 를 통째로 놓친다 (**치명적**)

`claim` 을 돌리기 **전에** SELECT 로 찾아 멈췄다. DB 는 그 시점에 아무것도 바뀌지 않았다.

**기전**: `_PRESERVED_JOBS_SQL` 과 `cmd_guard` 의 UPDATE 가 `left(j.session_id::text,8)` 로만 매칭했다.
그런데 **`analyze_utterance` 는 `session_id` 가 NULL 이고 `utterance_id` 로만 세션에 매인다**
(팀리드 실측: `analyze_utterance` **43건 전부** 그렇고 `plan_next_session` **6건**은 반대다).
`left(NULL,8) = any(...)` 는 NULL 이므로 그 행들이 조용히 빠진다.

| 술어 | claim 가능한 보존 job |
|---|--:|
| 초판(`j.session_id` 만) | **4** |
| 고친 판(`coalesce(j.session_id, u.session_id)`) | **7** |

놓친 3건은 전부 **C3a(`210233be`) 의 `analyze_utterance`** 이고, `claim_next` 는
`order by available_at limit 1` 이라 그 중 하나(`d3272c2c` · `2026-09-06 14:39:30.94136+00`)가
**보존 plan job 4건보다 5ms 이르다** → guard 를 돌린 뒤에도 **반드시 먼저 집힌다.**

**그때 무슨 일이 나는가**: `claim_next` 가 `attempts` 0→1 · `pending`→`running` 을 커밋한 뒤,
드라이버가 `job.session_id`(NULL)로 판정하므로 `exit 3` 방어를 **통과**하고 `--expect-session`
검사에서 `exit 4` 로 처리만 거부한다. ⛔ **그 쓰기는 남는다.**
그리고 `results.py:185` 가 `pending`·`running` 을 함께 non_terminal 로 세므로 결과 API 는 계속
`analyzing` 을 낸다 → **`verify` 대조가 이 손상을 구조적으로 못 잡는다**(`H-AT` 의 「피해가 눈에
안 보인다」와 같은 형태다). 5분(LEASE) 뒤에는 회수 대상이 되어 되살아나고, 반복되면 attempts 가
5에 닿아 reaper 가 terminal `failed` 로 만들어 **C3a 가 `partial_failure` 로 바뀐다.**

**고친 것 셋** — 팀리드 지시 그대로:

1. `_PRESERVED_JOBS_SQL` 에 `left join utterances` 를 넣고 `coalesce(j.session_id, u.session_id)` 로 해소
2. `cmd_guard` 의 UPDATE 를 **술어 복제가 아니라 스냅샷의 id 목록**(`where id = any($1::uuid[])`)으로
   바꿨다. ⛔ **결함의 뿌리가 「같은 집합을 두 곳에서 각자 계산한 것」이라서** id 로 묶으면
   스냅샷과 UPDATE 가 **갈릴 수 없다** — 되돌릴 근거가 없는 행을 비켜 두는 일이 사라진다
3. `cmd_claim` 이 claim 뒤 `job.session_id` 가 NULL 이면 **`utterance_id` 로 소유 세션을 해소**한다.
   이것을 빼면 `exit 3` 방어가 `analyze_utterance` 에 대해 영구히 눈이 먼다

### 2-2. 결함 B — `restore` 가 죽는다 (**guard 를 걸어 둔 채로 남는다**)

  '2026-09-06T14:36:53.840675+00:00' (expected a datetime.date or datetime.datetime instance, got 'str')

### 4-4. 판정 — **FAIL**

**학습자는 문법적으로 옳게 말했는데 `error_patterns` 에 패턴이 생겼고 복습 과제까지 예약됐다.**
그것이 P6 이 겨냥한 피해 그 자체다.

⚠️ **분석기가 「환각」을 낸 것은 아니다 — 그 구별을 판정과 함께 적는다.** 받은 텍스트에는 그 구절이
