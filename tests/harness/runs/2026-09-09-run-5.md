| 실패를 **통보**하는가 | **아니다** — 가드가 **서버 로그로만** 말하고 클라이언트에 프레임을 보내지 않는다 |

**판정**: 「조용히 죽지 않는다」는 **충족**, 「실패를 통보한다」는 **미충족**.
⚠️ **미충족을 결함으로 올리지 않는다** — 통보를 요구하는 요구사항 인용이 없고, **Nova 가 거부하지
않으므로 중계할 상류 실패가 애초에 없다.** 통보의 유일한 방아쇠는 앱 자신의 가드이고, 프레임
단위 드롭을 매번 통보하면 잡음이 된다. **관측으로 고정한다** — 통보가 필요하다는 판단이 나오면
그때 요구사항을 먼저 세운다.
정크 프레임 5종은 `A2`(스텁)와 **같은 다섯 갈래**로 처리됐다 — 실물 어댑터에서도 같다.

## `P10` `PASS` — `R11-9`·`AC11-6` 이 계약으로 닫혔음 (실물 0회)

## 마지막 실물 3건 — 세션 **1건**으로 합쳐 얻었음 (9차 시도)

위임이 `N6`·`N13`·`B-2` 를 **한 세션**(`e6206514`)에 합쳤다. teardown 은 팀리드가 했다.

**`N6` `PASS` (셋 다)** — barge-in 을 `recv.audio` 가 늘기 시작한 시점(@31,169 ms)에 걸었다.
① `interrupted` 프레임과 첫 `stop()` 이 둘 다 @31,507 ms — **338 ms** 로 1초 상한 안이다.
③ 큐 비움을 **두 겹**으로 확인했다: `stop()` **20회가 전부 같은 밀리초**에 인자 없이 호출되고
(`dropQueuedAudio()` 의 일괄 정지) `started.calls` 의 `when` 이 **3.967 → 0** 으로 떨어졌다
(`nextStartTime = 0` 의 효과). ⚠️ **계수만으로는 「멈췄다」와 「비웠다」를 못 가르므로 후자가
독립 증거다** — 위임이 그것을 스스로 갈랐다.
② ⛔ **위임은 「부분」으로 냈고 팀리드가 `PASS` 로 올렸다.** 근거: `nova.py:567` 의
`_on_content_end` 가 **`stopReason == "INTERRUPTED"` 일 때만** `InterruptionEvent()` 를 낸다
(직접 읽었다). 즉 앱의 `interrupted` 프레임은 그 문자열의 **충실한 파생**이고, 원본 문자열이
프레임에 없는 것은 포트 설계(기계값을 앱 이벤트로 번역)이지 미관측이 아니다.

**`N13` `PASS` — 위임이 `BLOCKED` 로 냈고 팀리드가 도구를 바꿔 닫았음.**
⛔ **위임의 진단이 정확했다**: `nova.py:429` 의 `_offset_ms` 가 `inputAudioOffsetMs` **하나만**
읽고 `inputAudioDetectionOffsetMs`(N-1 이 480 ms 의 근거로 쓴 필드)를 **중계하지 않는다**
(팀리드가 코드로 재확인). 그래서 **앱 경로로는 원리적으로 못 잰다.**
**그러나 N-1 의 기준선도 스파이크에서 나왔다** — 그래서 `spike_nova_protocol.py` 에
`--endpointing` 을 넣어 같은 도구로 대조했다:

| 민감도 | `inputAudioDetectionOffsetMs` | `inputAudioOffsetMs`(발화 끝) | 감지 지연 |
|---|--:|--:|--:|
| `MEDIUM` | **2,400** | 1,920 | **480 ms** |
| `LOW` | **2,520** | 1,920 | **600 ms** |
| `LOW` 재측정 | **2,520** | 1,920 | **600 ms** |

**발화 끝이 두 모드에서 1,920 으로 동일**한 것이 위임의 통찰을 확증한다 — 그 필드는 감지 지연이
아니다. **`MEDIUM` 의 480 ms 는 N-1 이 독립으로 기록한 값과 정확히 일치**하고, `LOW` 는
**+120 ms**(= 32 ms 프레임 4개)이며 재측정에서 같은 값이 나와 **흔들림이 아니다.**
**판정**: 민감도가 감지 시점을 실제로 바꾸고 `LOW` 가 더 늦게 끊는다 — mic-1 이 2026-09-01 에
`LOW` 로 내린 판단이 실측으로 뒷받침됐다. 표본은 모드별 1·2회다.

**`B-2` `PASS`** — 전사문 `i usually go to gym after work.` 가 N5 기대와 등호 일치하고 agent
2턴에 `pronounc`·`sound`·`발음`·`accent` 가 **0건**이며 `analyze_utterance` 가 사용자 발화 수와
같은 2건 `pending` 이다. **「학습 반영 부재」 기준선이 유지됐다.**
✅ **위임이 agent 문구를 등호로 대조하지 않은 것이 옳았다** — 문구는 회차마다 다르다(7차는
`did yesterday`, 9차는 `this weekend`). 사용자 전사문과 **발음 언급 부재**만 대조했다.
곁가지로 `interrupted` 뒤에도 세션이 2턴 완주하고 정상 종료했다.
