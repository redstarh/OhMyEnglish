## 2. 관측 하나 — 실린 값이 「문장」이 아니라 「교정된 구간」임

결정 99 ① 의 문면은 *"발음의 것은 학습자에게 보이는 **문장**이다"* 인데 실린 값은 `the report` 로
**구간**임. finding 의 계약이 `original_span`↔`correction` 쌍이므로 구간이 오는 것이 정상 경로임.

⛔ 결함으로 보지 않음 — 화면이 `내 발화` 와 짝으로 그리므로 학습자가 무엇을 어떻게 고칠지 읽을 수
있고, 문법 교정 카드도 같은 방식으로 구간을 그림. ⚠️ 다만 결정 99 ① 의 「문장」이라는 낱말이 한 칸
부정확함 — 다음에 그 항을 인용할 때 「finding 의 correction(구간)」으로 읽어야 함.
