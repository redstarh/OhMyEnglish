#### N5 상세 — AC1이 앱 경로로 처음 충족됐다

`VOICE_ADAPTER=nova`로 기동하고 브라우저에 `u1.wav`(1.92초, 16kHz)를 `getUserMedia` shim으로
주입했다. **스텁 픽스처가 아니라 실제 오디오가 전사문을 결정한다.**

```
recv: session_started 1 · speech_start 1 · speech_end 1 · partial 2 · final 3 · audio 67
sent: 806 프레임 / 806 KB  (AudioWorklet raw PCM, 무음 포함 지속 스트리밍)

final/user     'i usually go to gym after work.'          ← Nova ASR = 픽스처 문장과 일치
partial/agent  'That's great! Going to the gym after work helps many people relax.'
partial/agent  'What time do you usually go to the gym?'
final/agent    (위 둘이 completionEnd에서 확정 승격)
```

DB (세션이 `active`인 동안 조회):

| seq | speaker | transcript | job |
|--:|---|---|---|
| 1 | user | `i usually go to gym after work.` | **`done`** |
| 2 | agent | `That's great! Going to the gym after work helps…` | (없음) |
| 3 | agent | `What time do you usually go to the gym?` | (없음) |

**확인된 계약 4개**: ① 전사문이 실제 발화 내용이다(AC1) ② **user 발화에만 job**(W6 유지)
③ agent 발화도 저장된다 ④ **세션이 `active`인 동안 job이 `done`에 도달**(W1 관측형).
화면 증거: `2026-08-26-run-3/N5-real-voice.png`

**수정 세션의 설계 판단 2개가 실제로 필요했음이 확인됐다**:
- `SPECULATIVE` → `kind=partial` 매핑 — `partial/agent` 2건으로 관측
- **ASSISTANT 텍스트를 `completionEnd`에서 확정 승격** — 이게 없으면 agent 질문이
  `partial`로만 와서 전사문에 남지 않는다(`session.py` 계약 1: partial 미저장). 실제로
  agent 2건이 `utterances`에 저장됐다
