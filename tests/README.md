# 테스트 전략

- `unit/`: 복습 우선순위, 숙련도 계산, 오류 패턴 정규화
- `integration/`: 전사문 → 오류 검출 → 패턴 upsert → 복습 과제 생성
- `e2e/`: 온보딩 → 음성 세션 → 교정 → 주간 리포트 흐름

필수 테스트 케이스:

1. 같은 오류가 다른 문장에 나타나도 하나의 패턴으로 병합되는가
2. 세션 피드백이 최대 두 개의 핵심 오류만 선택하는가
3. 사용자가 녹음을 삭제하면 연결된 음성 URL이 노출되지 않는가
4. 1·3·7일 복습 일정이 중복 없이 생성되는가
5. 일일 목표 완료 뒤에도 `additional` 세션을 제한 없이 시작할 수 있는가
6. “질문 다섯 개 더”는 음성 명령으로 기록되며 학습자 오류 분석에는 포함되지 않는가
7. “오늘 학습 끝낼게”는 종료 전에 확인 단계를 거치는가
