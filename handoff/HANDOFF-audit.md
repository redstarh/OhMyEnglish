## 6. 실측 환경 함정 — 여기서 실제로 걸렸다

- **`grep`이 셸 함수로 덮여 있다**(`ugrep -I` 래퍼). `grep -c`가 **빈 출력 + exit 1**을 낸다 → **`/usr/bin/grep`을 쓴다.**
- **`ls`는 `eza` 별칭이다.** `ls -1t`가 아무것도 안 낸다 → `find` + `stat`을 쓴다. 인용부호가 섞여 나오므로 경로를 넘길 땐 파이썬으로 읽는다.
- 위 둘 다 **빈 출력을 "없음"으로 오독하게 만든다.** 출력이 비면 **exit code를 먼저 본다.**
- ⚠️ **그 방어를 뚫는 형태가 있다 — `NUL`이 든 파일**(`tests/harness/instrument.js`: byte 15764·15784, 2026-09-06 실측). `/usr/bin/grep -n`·`command grep -n`이 줄을 숨기고 **`Binary file … matches` + rc=0**을 낸다. **출력이 비지 않고 rc도 0이라서 위 규칙에 걸리지 않는다.** `-c`는 정상값(37)을 내므로 개수만 보면 이상을 못 느낀다.
  → **`file:line`을 인용할 파일에는 `-a`를 붙인다**(`/usr/bin/grep -an`). 셸 래퍼조차 `-an`은 정상 동작한다. 확실히 하려면 파이썬으로 읽는다. 원장 함정 등록명은 `H-AG`이고 `TASK-31` AC #16이 NUL 제거를 소유한다.
  ⚠️ 작업 세션의 초기 완화책 *"`command grep`을 쓰라"*는 **불충분하다** — `-n`에서 여전히 숨는다. 관건은 `-a`다.
- **원장의 `created_date`·`updated_date`는 UTC다.** KST와 9시간 어긋난다 — 시각차로 착수 지연을 논할 때 보정하고, 파일 mtime·커밋 시각으로 교차 확인한다.
- **`backlog board export`에 절대경로를 줘도 리포 안에 떨어진다**(`/tmp/x.md` → `<repo>/tmp/x.md`).
- `sed -n '/제목/,/^$/p'`로 절을 뜨면 **첫 빈 줄에서 끊긴다** — 비어 있다고 오판했다. 절 마커(`SECTION:...`)로 뜬다.
