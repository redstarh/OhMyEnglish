**대신 쓴 것 — 세션 이름에서 접두사를 유도한다** (이번에 실제로 통과한 형태):

```bash
CUR=$(tmux display-message -p '#{session_name}')     # claude_air_1-1
PREFIX="${CUR%-*}"                                    # claude_air_1
LAST=$(tmux ls -F '#{session_name}' | sed -n "s/^${PREFIX}-\([0-9]*\)$/\1/p" | sort -n | tail -1)
NEW="${PREFIX}-$((LAST+1))"                           # claude_air_1-2
```

**정리 순서는 §6 그대로 쓸 수 있다** — 양쪽이 tmux 안이라 이번엔 상대가 있다:
새 세션이 4개 지표를 직접 돌려 보고 → **이전 세션이 대조하고 그 결과를 이 파일에 적는다** →
이전 세션 `/exit` → **새 세션이** `tmux kill-session -t claude_air_1-1`.
⚠️ **자기 자신을 kill 하지 않는다**(확인 기록을 남길 주체가 사라진다) ·
**4개가 데이터로 일치하기 전에 이전 세션을 정리하지 않는다.**
