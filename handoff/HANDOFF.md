## ② 지금 상태 — 새로 생긴 계약

- **낭독 전달 형식이 `audio/wav` 임**(앞 판은 `audio/L16`). ⛔ **저장은 헤더 없는 `.pcm` 그대로이고
  변환은 읽을 때만 함** — 저장 쪽에 헤더를 얹으면 §6 의 스윕·고아 파일 판정이 바이트 길이를 다시
  계산해야 함. `wav_from_pcm` 이 그 자리이고 `api/results.py` 가 HTTP 경계에서 부름.
- **서버가 낭독 턴을 닫을 때 `shadowing_recording` 프레임으로 `utterance_id` 를 알림.**
  ⛔ **저장에 실패한 턴에는 보내지 않음** — 화면이 404 를 받는 버튼을 보이지 않게 하는 유일한 근거임.
  세션 주소는 싣지 않고 화면이 `API_BASE` + 세션 id + 발화 id 로 조립함(클립 오디오와 같은 관행).
- **`ShadowingPanel` 이 「내 낭독 듣기」를 가짐.** 녹음이 저장된 뒤에만 보이고 녹음 중에는 잠김.
  ⛔ **클립과 낭독이 한 `audio` 요소·한 `playing` 값을 공유해 두 소리가 겹치지 않음이 구조로 보장됨.**
- ⛔ **「비교」는 여전히 범위 밖임** — 원본과 나란히 견주기·파형·점수를 만들지 않음(결정 128 ①).
- **낭독 재생에는 결정 6 의 속도·반복을 걸지 않음** — 그 값역은 「원본을 어떻게 들려줄 것인가」임.

## ③ 착수 전 필수 — 이 세션 실측

1. ⛔ **`pytest`·`ruff` 는 `app/backend` 에서 돌림**(`H-BN`). 부분 실행은 `-c pyproject.toml`(`H-AJ`).
2. ⛔ **한글 주석을 쓴 직후 `ruff check`** — `E501` 은 표시 폭이라 한글이 2열임(`H-BW`).
   ⚠️ 이 세션에서 `ruff format` 이 빈 줄 하나를 고쳤음 — 주석 블록을 더하면 포맷을 함께 돌림.
3. ⛔ **종료 코드 판정에 파이프를 걸지 않음**(`H-AZ`). `grep -c` 는 0건이면 exit 1 임.
4. ⚠️ **프런트에 테스트 러너가 없음** ⇒ 화면 판정은 **브라우저 관측이 유일**함. 게이트 여덟이
   초록이어도 브라우저에서만 막히는 것은 잡히지 않음(`H-CA`·`H-CB`·`H-CC`).
5. ⚠️ **브라우저 자동화에 오디오 장치가 없음** — `AudioContext` → `MediaStreamDestination` 으로
   `getUserMedia` 를 갈아 끼움. ⛔ 심는 시점은 **세션을 열기 전**이어야 함(`H-CC`).
6. ⛔ **라벨만 보고 재생을 판정하지 않음** — 디코드 실패도 `stop()` 이 라벨을 되돌려 **같은 화면**이 됨.
   `Audio` 를 감싸 `loadedmetadata`·`playing`·`error` 를 따로 기록하고, 「겹치지 않음」은 **요소를 들고**
   `paused`·`currentTime` 을 읽음. 이 세션이 그렇게 잼(상세는 `TASK-183` 노트).
7. ⚠️ **실물 Nova 검증 형태**: `:8014` 에 `WORKER_ENABLED=false VOICE_ADAPTER=nova` 를 띄우고
   `app/frontend/.env.local` 의 `NEXT_PUBLIC_API_BASE` 만 그쪽으로 돌림(검증 뒤 되돌림 · 프런트 재기동).
   ⛔ **프런트를 다른 포트에 띄우는 길은 막혀 있음** — `FRONTEND_ORIGIN` 이 `:3000` 하드코딩임.
8. ⛔ **`git add <디렉터리>` 금지** · 커밋 뒤 `git show --stat` 으로 담긴 것 전체를 봄.

⚠️ **나머지 일반 함정의 정본은 `docs/ops/pitfalls.md` 임.**
